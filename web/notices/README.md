# Hand-kept licence texts

`scripts/web_notices.py` builds `web/THIRD_PARTY_NOTICES.md` from the wheels and npm packages themselves, and from the
texts here for what they leave out. Each file starts with `For: <name> <version>`: the component and version it was
verified against. The script fails when the page bundles another version, so a bump means verifying the file again,
then changing that line. A wheel supplement (`wheels/<name>.md`, the normalized distribution name) is added after the
licence files the wheel ships. Its header goes on with `Pyodide: <version>` and `Emscripten: <version>`: what it
records is how that Pyodide builds the wheel (what the recipe links, which Emscripten ports), so a new Pyodide fails
every supplement until it is checked again. The script fails if the wheel is no longer bundled, and on any `.md` here
it does not read.

The texts are verbatim. The only change is that CRLF line ends became LF (the Humor Sans OFL text). Each section's `Source:` line
names the upstream file at the pinned ref. Verified on 2026-11-03/04 as follows.
